# Independent security review — 2026-08-27

The first read-only review found three high and four medium issues: forgeable
repository-only approvals, prompt-injection ambiguity, mutable install sources,
shell-command ambiguity, remote credential leakage, prompt-only worker ownership,
and missing CI security enforcement.

Remediation adds authenticated approval provenance, instruction/data isolation,
tag-pinned release installation, approved direct-argv commands, remote redaction,
worker path enforcement, and CI secret/dependency/static checks. A second
security review is required before the branch is trusted.

GitHub dependency review was attempted but the repository does not expose a
dependency graph. Because Flow42 has no product dependency manifests, CI instead
asserts their absence and requires every GitHub Action reference to be a full
commit SHA. Adding a dependency manifest fails until its ecosystem scanner is
added.
